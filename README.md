💌 Myra — Interactive Confession Letter

«A romantic, interactive digital confession letter created with pure HTML, CSS, and JavaScript.»

A small web experience designed around a handwritten-style confession letter for Myra.

The project combines a romantic envelope-opening animation, an interactive letter, floating hearts, elegant typography, responsive layouts, and a celebration sequence to create something that feels more like an experience than a normal webpage.

💻 How to Run

No build system or installation is required.

Option 1 — Open directly

Download or clone the project and open:

index.html

in a modern web browser.

Option 2 — SPCK Editor

This project can also be created and edited entirely on mobile using SPCK Editor.

Create three files:

index.html
style.css
script.js

Keep all three files inside the same project folder.

Then open "index.html" using the preview/browser option.

---

📱 Responsive Design

The project is designed to work across different screen sizes, including:

- 📱 Smartphones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop monitors

The layout uses responsive CSS techniques such as:

clamp()

min()

max-width

and responsive media queries.

The goal is to keep the confession experience visually comfortable regardless of the device being used.

---

🎨 Customization

You can personalize the project by editing the content inside "index.html".

For example:

Recipient

<h2 class="letter-greeting">Hi Myra,</h2>

Letter content

Edit the paragraphs inside:

<div class="letter-body">

Signature

<span class="signature-name">
  Your Secret Admirer 💘
</span>

You can also change the colors, shadows, typography, animations, and responsive behavior inside "style.css".

Interactive behavior and effects can be modified inside:

script.js

---

🌹 Design Philosophy

This project was designed to feel like a digital love letter rather than a normal website.

The animations are intentionally soft and romantic:

- slow floating hearts
- gentle transitions
- envelope opening
- paper-like letter design
- handwritten typography
- subtle sparkles
- heart animations
- celebratory confetti

The goal is to make opening the letter feel like opening something personal and meaningful.
